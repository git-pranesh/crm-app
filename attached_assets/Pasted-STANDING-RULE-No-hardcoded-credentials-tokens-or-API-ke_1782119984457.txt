PART 1 — MEETINGS PAGE (client/src/pages/Meetings.tsx)

Route: /meetings. Already registered in nav as "Meetings".

### Top KPI bar (4 cards, matches mockup):
  Upcoming — count of meetings with status SCHEDULED and 
              scheduledAt >= now
  Completed — count COMPLETED
  No-show — count NO_SHOW
  Total — all meetings in scope

### Tab bar: Upcoming (N) | Past (N)
- Upcoming: meetings where status=SCHEDULED, scheduledAt >= now, 
  sorted ascending (soonest first)
- Past: meetings where status in [COMPLETED, RESCHEDULED, NO_SHOW], 
  sorted descending (most recent first)

### Meeting card layout (grid, 3 per row on desktop):
  Top row: client name (bold) + Lead ID chip, status badge 
    (Scheduled/Completed/No-show/Rescheduled — colored)
  Row 2: meeting type chip (PP1/PP2/DQL/etc.) + mode chip 
    (Virtual/Site Visit/EC Visit/Public Place)
  Row 3: calendar icon + date + time
  Row 4: agenda/purpose text (use meeting type label: 
    "Proposal presentation", "Initial design consultation" etc.)
  Bottom row: assignee avatar + name (left), action buttons (right):
    - If status=SCHEDULED: "No-show" button (outline) + 
      "Complete" button (orange/terracotta filled)
    - If status=COMPLETED: show "MOM sent" badge, no action buttons
    - If status=RESCHEDULED: show "Rescheduled" badge + reason snippet
    - If status=NO_SHOW: show "No-show" badge

### Complete flow (triggers on "Complete" button click):
  Modal with:
  - MOM textarea (mandatory, blocks submit if empty)
  - Outcome textarea (mandatory)
  - On submit: PATCH /api/meetings/:id/status { status: "COMPLETED", 
    mom, outcome }
  - On success: card updates in-place to COMPLETED state

### No-show flow (triggers on "No-show" click):
  Modal with:
  - Reason textarea (mandatory, per spec: "someone cannot simply 
    click no-show, they should give a reason")
  - On submit: PATCH /api/meetings/:id/status { status: "NO_SHOW", 
    rescheduledReason: reason }
  - On success: card updates to NO_SHOW state

### Role scoping:
  DESIGNER/CRE: GET scope = only their own meetings
  BL: all meetings across their team's leads
  BRANCH_HEAD: all meetings
