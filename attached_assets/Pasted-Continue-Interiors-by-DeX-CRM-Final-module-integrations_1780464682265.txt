META LEAD ADS INTEGRATION:
- Verify webhook: GET /api/leads/webhook/meta (returns hub.challenge for Meta verification)
- Receive leads: POST /api/leads/webhook/meta (verify X-Hub-Signature-256, parse leadgen_id, fetch lead data from Graph API using PAGE_ACCESS_TOKEN, create lead)
- Env: META_PAGE_ACCESS_TOKEN, META_APP_SECRET, META_FORM_ID

GOOGLE ADS INTEGRATION:
- Receive via Google Ads webhook or Zapier webhook fallback
- POST /api/leads/webhook/google — parse UTM params, create lead, assign to CRE

QUOTE BUILDER INTEGRATION:
- Embed proposals.interiorsbydex.com in lead detail (iframe with ?leadId=X#### pre-filled)
- Webhook: POST /api/quotes/callback — Quote Builder posts back when quote created: leadId, amount, discountPct, quoteRef
- On receive: create Quote record, update lead.estimatedValue, log to ActivityLog
- Discount authority check: GET /api/users/:id/discount-authority — returns maxDiscountPct for designer. Quote Builder calls this before allowing discount submission.

BULK IMPORT:

- Dry-run mode: ?dryRun=true — returns preview of what would be imported, errors, duplicate count
- Production run: import valid rows, return summary
