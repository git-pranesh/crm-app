## UI/UX SPECIFIC CHECKS (across all pages)

For each issue found, note: page, element, severity.

U1. Loading states: is there a skeleton/spinner on every page 
    while data fetches? Or does content pop in with a flash?

U2. Empty states: for every table/list/chart with no data, is 
    there a helpful empty state message? Or blank whitespace?

U3. Error states: disconnect from internet (or pass bad token) 
    — does the app show an error message? Or does it hang/crash?

U4. Toast notifications: do success/error toasts appear after 
    form submissions? Are they visible long enough to read?

U5. Mobile-ish width (resize browser to ~768px):
    - Does the sidebar collapse?
    - Is the hamburger menu reachable?
    - Do tables scroll horizontally (not overflow and break layout)?

U6. Overflow checks:
    - Long lead names — do they truncate or overflow their card?
    - Long reason text in discounts — does it wrap correctly?
    - Long WhatsApp messages — do they wrap in the bubble?

U7. Color consistency:
    - Is the terracotta/coral accent color used consistently?
    - Are stage pill colors the same across Pipeline, Lead List, 
      and Lead Detail?
    - Are CTA buttons consistently orange/terracotta?

U8. Typography:
    - Is there consistent font size hierarchy 
      (h1 > h2 > body > caption)?
    - Are labels and values distinguishable (label lighter, 
      value bolder)?

U9. Form validation:
    - On every form: try submitting empty → are required fields 
      highlighted with specific error messages?
    - Are error messages next to the field (not just a top-level toast)?

U10. Relative timestamps:
     - "14d ago", "2h ago" etc. — do they show on lead cards, 
       activity feeds, WhatsApp messages?
     - Any showing raw ISO timestamps instead of relative time?

U11. Avatars/initials:
     - Do all user avatars show initials when no profile photo?
     - Are colors consistent per user across pages (same user = 
       same color)?

U12. Responsiveness of charts:
     - Do recharts charts resize correctly when window is resized?
     - Do they render on first load or require a resize to appear?
